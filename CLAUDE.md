# CLAUDE.md

Единый источник правды по инструкциям агента — [AGENTS.md](./AGENTS.md).

Кратко для Claude/подобных агентов:

- Читай `AGENTS.md` перед началом работы
- Следуй процессу: план → исследование → реализация → проверка → фиксация
- Пакет чистый: без IO, DOM, Node-инфраструктуры и Colyseus
- Не дублируй типы и правила из `game-overrule-shared` в клиенте или сервере
- Комментарии в коде — на английском
- После изменений: `npm run typecheck && npm run build`, `dist/` — в коммит
- Не коммить без явной команды пользователя
- Значимые решения по контракту фиксируй в ADR репозитория клиента
